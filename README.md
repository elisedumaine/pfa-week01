Fantasy Island Simulator — A2

What it does now that it could not do before: Fantasy Island Simulator has become a customizable seasonal world-building tool rather than one fixed island.
An artist can make a broken C-shaped world with an inhabited outpost and a necklace of small rocky side islets, choose a terrain-conforming lake or valley-following river, choose clear/rain/snow weather, populate a village with different house and tree archetypes, small sheep families, lantern-lit roads, and black creatures, drag through a many-shaded 24-hour sky with a moving sun, moon, wide horizon ocean, and save/load a reusable JSON blueprint. I designed it for a cozy island-simulator: the player shapes a living settlement where weather, landscape, water, seasons, and sunlight belong together. Winter now adds snow on roofs and castle towers, ground snow, and ice floes—not only new leaf colours. And i added lighting ! I added a moon and a sun. The sea is wider.


Fantasy Island Simulator — A1

"Fantasy island tool" is a 3D island low-poly environment tool in Maya, that allows the user to change various elements of the scene using a GUI.
To run it, open the Python script in Maya and execute it to launch the GUI.
In the future, I would add more environment options and make the seasonal changes more detailed.
